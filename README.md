# Biel Play — Site final

Site estático e responsivo, pronto para GitHub Pages.

## Arquivos
- `index.html`
- `styles.css`
- `script.js`
- `assets/`

## Publicação no repositório existente
1. Faça backup do repositório atual.
2. Substitua os arquivos da raiz pelos arquivos desta pasta.
3. Copie a pasta `assets` completa.
4. Faça commit e push na branch publicada pelo GitHub Pages.
5. Aguarde o deploy.
